# 微信遥控台 📱💻

给挂机电脑装一个微信入口：用个人微信给机器人发一条消息，本机就执行对应命令并把结果发回来。
走**腾讯官方 iLink Bot API**（2026 年开放，扫码登录）——不 Hook、不逆向协议、不锁微信版本。
纯 Python 标准库，零依赖，clean-room 原创实现。

## 它能干什么

```
/状态            电脑系统、磁盘余量、运行时间
/进程            主要进程一览
/截图            截屏保存（回传本机路径；图片直发在路线图）
/文件 报告        在白名单目录里找文件
/提醒 30m 喝水    定时提醒，到点微信推送给你
/每天 07:30 /稿件  每日定时执行任意指令
/跑 稿件          运行 config 里登记的本地任务，进度与结果回传微信
/关机 10 ⚠️      危险操作：锁屏、关机、打开程序都要回复「确认」才执行
直接发文字        转对话后端（可接 DeepSeek 等 OpenAI 兼容接口，可关）
```

典型用法：电脑在家 24 小时开着，人出门在外，微信发 `/稿件`，
家里的公众号写作流水线就跑起来，跑完把标题清单发回手机；发 `/状态` 随时看机器死活。

## 快速开始

```bash
python main.py --demo     # 离线演示：模拟一段完整对话（不连微信、不真关机）
python main.py --login    # 扫码登录 iLink（凭证只存本机 state/，不经过任何聊天）
cp config.example.json config.json   # 按需改：白名单目录、程序、任务、AI 后端
python main.py            # 正式运行；本地管理页 http://127.0.0.1:8760（状态/审计/指令）
python run_tests.py       # 32 项测试（含本地假 iLink 服务器契约测试）
```

**绑定主人**：首次启动控制台会显示 6 位配对码，在微信里给机器人发 `/配对 123456`，
第一个发对的人成为主人，之后只有主人能下令，陌生人消息一律静默忽略，配对码随即失效。

## 安全设计

- **主人制**：配对绑定 + 主人名单持久化，非主人零响应；
- **二次确认**：关机/锁屏/开程序/跑任务等危险命令，60 秒内回复「确认」才执行，发别的内容自动取消；
- **白名单**：可找的文件目录、可开的程序、可跑的任务，全部在 config 里显式登记，没有任意命令执行；
- **审计**：每条指令（谁、何时、内容、结果）落 JSONL 日志，管理页可查；
- **凭证本地化**：bot_token 只存在本机 state 目录，不进仓库、不经聊天传输。

## 与同类方案的区别

| 路线 | 代表 | 问题 |
|---|---|---|
| PC Hook | WeChatFerry 等 | 锁死老版本微信，属于外挂，有封号风险 |
| iPad 协议 | Gewechat 等 | 已停止维护 |
| RPA 模拟 | wxauto 等 | 界面改版即失效、锁屏不可用 |
| **iLink 官方（本项目）** | 腾讯 ClawBot / iLink Bot API | 仅私聊、纯文本、会话过期需重扫——但官方、合规、不挑版本 |

功能形态参考了"微信 ↔ 本机 Agent"这一产品方向（如 codex-weixin），
本项目为原创实现：遥控命令集、配对鉴权、危险确认、定时调度、任务编排均为自研，
iLink 客户端依据公开协议文档编写。设计取舍见 [DESIGN.md](DESIGN.md)。

## 已知边界

- iLink 客户端按公开协议文档实现，真实账号联调前登录细节属 best-effort；
  文本收发的协议契约已用本地假服务器测试覆盖。会话过期（errcode -14）会明确提示重扫，不会静默失效。
- 机器人是独立身份，仅私聊可用；图片/文件直发微信需 CDN 加密上传流程，在路线图上。
